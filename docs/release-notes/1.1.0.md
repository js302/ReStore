# ReStore 1.1.0

Released 2025-10-08 · [GitHub release](https://github.com/js302/ReStore/releases/tag/v1.1.0.0)

## What's New

### Windows Settings Backup

ReStore can now backup and restore Windows registry settings including personalization, File Explorer preferences, taskbar configuration, regional settings, mouse/keyboard settings, and more.

**Usage:**
- GUI: System Restore page → Settings card → Backup button
- CLI: `restore system-backup local settings`

**Important:** Some settings require administrator privileges to restore. Always review the generated restore script before running it.

## Changes

- Added Windows Settings backup with 8 setting categories
- Updated System Restore page with new Settings tab
- Enhanced documentation with settings backup details

## Notes

- Settings are exported as registry files with PowerShell restore scripts
- Hardware-specific settings may not be appropriate for different machines
- WiFi passwords and network credentials are not included
