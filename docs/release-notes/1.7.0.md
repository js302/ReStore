# ReStore 1.7.0

Released 2026-08-30 · [GitHub release](https://github.com/js302/ReStore/releases/tag/v1.7.0)

This release moves ReStore to .NET 10 and adds ARM64 installers. First-run setup, scheduled backups, integrity verification and restore previews are new; existing configs migrate automatically on first launch.

## First-Run Setup

- **Setup wizard**: Starting ReStore with no configuration now opens a three-step wizard - pick folders, choose a storage provider with a live connection test, then optionally turn on encryption.
- Skippable if you'd rather configure everything from Settings directly.

## Progress and Cancellation

- **Progress window**: Manual backups, restores and verifications now show the current phase, per-file and per-byte counts, and a live log instead of leaving you guessing.
- **Cancellation**: Long operations can be cancelled and stop at the next safe point. A cancelled backup leaves your previous snapshot as the current one, and a cancelled restore never leaves a half-written file behind.

## Restore Safety

- **Preview before writing**: Restores now show what they'd actually do first - how many files, total size, and which ones already exist at the target.
- **No accidental overwrites**: Existing files are skipped by default. Overwriting, or restoring alongside as `name (restored).ext`, is now an explicit choice.
- Program restore got matching options for how to handle programs that are already installed.

## Scheduled Backups

- **Interval scheduler**: Backups now run on `backupInterval` and `systemBackup.backupInterval` even if the app was closed or the machine was asleep - the file watcher only ever saw changes made while it was running.
- Due times are based on the last recorded backup, so restarting ReStore no longer resets the clock.

## Scheduled Verification

- **Background integrity checks**: Snapshots can be re-verified on a schedule (`verification` config block, off by default) to catch bit rot or a storage provider quietly losing a chunk.
- Defaults to local storage only and a couple of snapshots per run, so it won't run up bandwidth on metered providers.

## Notifications

- **Tray notifications** for backup and verification failures, and for recovery once things pass again (`notifications` config block).
- Stays quiet on routine success by default, and respects Windows' own notification suppression (focus assist, presentation mode).

## Backup Labels

- **Named snapshots**: Backups can be tagged with a label like "before Windows reinstall" so you're picking from names rather than timestamps.

## Windows Settings Backup

- System backup can now include Windows settings alongside programs and environment variables (`systemBackup.includeWindowsSettings`, on by default).

## Platform and Packaging

- **.NET 10**: Upgraded from .NET 9. The installer is self-contained, so no separate runtime install is needed.
- **ARM64 Support**: Native `win-arm64` build alongside `win-x64`, so ARM devices (Snapdragon X, Surface) no longer run under x64 emulation.
- Separate signed MSIX installers are now produced for each architecture.

## UI Fixes

- **Fixed scrolling getting stuck** on the Dashboard and Settings pages. Scrolling over a card with its own scrollbar swallowed the wheel and the page stopped moving until you dragged the scrollbar by hand.
- **Fixed blurry small text**. Card shadows were disabling ClearType, and the app wasn't declaring DPI awareness, so Windows was bitmap-stretching the whole window at scaling above 100%. Most noticeable on high-resolution displays.
- Layout rounding and text rendering hints are now applied consistently across every dialog window.

## Memory

- **Chunk streaming**: Chunks are now handed off as they're produced instead of being collected in memory, so backing up a large file peaks at roughly one chunk rather than the whole file.

## Configuration

- Config schema is now version 4. Existing configs migrate automatically on load, and missing sections get filled in with defaults even if the version stamp already looks current - a hand-edited or truncated config repairs itself now.
- The example config no longer ships with provider names filled in for individual folders, which was misleading when you'd only set up one provider.

## Bug Fixes, Optimizations, and Cleanup

- Stability fixes across backup, restore, monitoring, storage integrations and GUI flows.
- Byte-size formatting was duplicated in multiple places; now it's a single shared implementation.
- Config and system state are shared across pages, so one page saving can no longer discard another page's unsaved edits.

## Documentation

- Documentation updates across configuration, architecture, features and usage guides, including new pages for the chunk and manifest model and the encryption architecture.

## Tests

- Test suite expanded across the scheduler, restore preview, progress and cancellation, chunking, dedup telemetry, backup labels and scheduled verification.
